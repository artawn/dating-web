# یه سوال کوچولو 💌 — راهنمای پروژه

## ساختار پوشه‌ها

```
index.html              <- کل سایت (HTML+CSS+JS تو همین یه فایل)
save.php                <- جواب‌های نهایی رو ساکت می‌فرسته و رو خودِ هاست ذخیره می‌کنه
view.php                <- صفحه‌ی خصوصیِ خودت برای دیدن جواب‌ها (با رمز)
data/
  .htaccess              <- جلوی دسترسی مستقیم به فایل داده‌ها رو می‌گیره
  submissions.json        <- خودش ساخته می‌شه، جایی که جواب‌ها ذخیره می‌شن
assets/
  videos/
    background1.mp4     <- پلی‌لیست ویدیوی پس‌زمینه (اختیاری)
    background2.mp4
    background3.mp4
    nikki.mp4            <- ویدیوی اوجِ مرحله‌ی ۱ (سوال اصلی) (اختیاری)
    nikki2.mp4           <- ویدیوی اوجِ مرحله‌ی ۲ (تاریخ/ساعت) (اختیاری)
    nikki3.mp4           <- ویدیوی اوجِ مرحله‌ی ۳ (انتخاب مکان) (اختیاری)
  music/
    song1.mp3            <- پلی‌لیست موزیک پس‌زمینه، پخش خودکار (اختیاری)
    song2.mp3
    song3.mp3
  sounds/
    glitch.mp3           <- افکت صدای لحظه‌ی چهارم هر مرحله (اختیاری)
```

هیچ‌کدوم از فایل‌های ویدیو/موزیک بالا اجباری نیستن. همین الان که هیچی
داخلشون نیست، سایت کامل و قشنگ کار می‌کنه. هر وقت فایل‌ها رو با همین
اسم‌های دقیق اضافه کنی، خودکار جایگزین می‌شن - نیازی به تغییر کد نیست.

## چطور ببینمش؟

برای تست رو سیستم خودت، کافیه `index.html` رو باز کنی (فقط قسمت ذخیره‌ی
جواب‌ها روی هاست کار می‌کنه، چون نیاز به PHP داره - پایین‌تر توضیح دادم).
برای اینکه پارتنرت واقعی ببینتش، باید کل پروژه رو یه هاست PHP آپلود کنی -
بخش «آپلود روی هاست» رو ببین.

## داستان مراحل

هر سه مرحله‌ی اول (سوال اصلی، تاریخ/ساعت، انتخاب مکان) یه دکمه‌ی «نه» دارن،
ولی هر کدوم رفتار متفاوتی داره:

- **مرحله‌ی ۱ (سوال اصلی):** دکمه‌ی «نه» با نزدیک شدن موس یا لمس گوشی
  **فرار می‌کنه** و کل صفحه رو می‌گرده. بعد از **۵ بار** فرار، وارد لحظه‌ی
  اوج می‌شه.
- **مرحله‌ی ۲ (تاریخ/ساعت):** دکمه‌ی «نه» فرار نمی‌کنه - **سرجاش می‌مونه**
  و فقط با هر بار زدنش **کوچیک‌تر** می‌شه. بعد از **۳ بار** زدن، وارد لحظه‌ی
  اوج می‌شه.
- **مرحله‌ی ۳ (انتخاب مکان):** دکمه‌ی «نه» هم سرجاش می‌مونه، ولی به‌جای
  کوچیک شدن، هر بار زدنش **فونت و شکلش عوض** می‌شه (وزن/سبک فونت و
  بردر-رادیوس تصادفی). بعد از **۴ بار** زدن، وارد لحظه‌ی اوج می‌شه.

تو هر سه مرحله، هر بار که «نه» زده بشه، فضای صفحه یه پله تاریک‌تر/سردتر/
لرزون‌تر می‌شه (تاریکی و افت نور و موزیک، رنگ سردتر و لرزش، وینیت و بلور،
چشمک+افکت صدا). دکمه‌ی اصلیِ هر مرحله (آره / بعدی / تمومه) همیشه و مستقل
از این جریان کار می‌کنه.

آخرین باری که «نه» زده می‌شه (۵ام تو مرحله‌ی ۱، ۳ام تو مرحله‌ی ۲، ۴ام تو
مرحله‌ی ۳)، وارد یه لحظه‌ی سینمایی می‌شیم: خودِ دکمه کوچیک و محو می‌شه،
چشمک، افکت گلیچ، صفحه سیاه، و ویدیوی مخصوص همون مرحله (nikki / nikki2 /
nikki3) تمام‌صفحه پخش می‌شه - **درست همون لحظه، ویدیوی پس‌زمینه و موزیک
کاملاً ساکت می‌شن.** همزمان، دکمه‌ی اصلی مرحله (آره/بعدی/تمومه) بزرگ‌تر و
با گلوی بیشتر می‌شه و میاد وسط‌تر، تا واضح باشه الان نوبت کلیک کردن رو
اونه. بعد از تموم شدن ویدیو (یا لمس برای رد شدن)، یه جمله‌ی کوتاه میاد و
بعدش می‌ره مرحله‌ی بعد؛ پس‌زمینه و موزیک هم به‌آرومی برمی‌گردن.

1. **صفحه‌ی اول** - «حاضری باهام بیای بیرون؟» → اوج: `nikki.mp4`
2. **تاریخ و ساعت** - تقویم شیشه‌ای دست‌ساز شمسی + انتخاب ساعت → اوج: `nikki2.mp4`
3. **انتخاب مکان** - ۶ کارت (کافه، شهربازی، رستوران، دوردور، پیاده‌روی شبانه،
   سینما) + آدرس → اوج: `nikki3.mp4`
4. **پیام آخر** - بدون دکمه‌ی «نه» و بدون این مکانیزم؛ فقط پیام پایانی،
   قلب‌های خروجی، کانفتی، و فید موزیک. همین‌جا، بدون هیچ نشونه‌ای رو صفحه،
   جواب‌ها ساکت می‌رن روی هاست ذخیره می‌شن (بخش بعدی رو ببین).

در تمام مراحل: شیشه‌ای‌بودن (Glassmorphism)، نور دنبال‌کننده‌ی موس،
پارالاکس، ذرات شناور، ریپل روی دکمه‌ها، و موزیکِ خودکار هست.

## جواب‌ها رو کجا می‌بینم؟

هیچ فایلی رو سیستم پارتنرت دانلود نمی‌شه - این عمداً همینطوریه که سوپرایز
خراب نشه. به‌جاش، همین که به مرحله‌ی ۴ برسه، خودِ سایت ساکت (بدون هیچ
نشونه‌ای رو صفحه) اطلاعات رو با `fetch` می‌فرسته به `save.php` رو همون
هاست، و اونجا تو فایل `data/submissions.json` ذخیره می‌شه.

برای دیدنش، برو به:

```
https://سایتت.com/view.php?key=NETpKWZLfiVkVimmjvMd
```

**قبل از آپلود روی هاست، حتماً این رمز رو عوض کن** - بازش کن `view.php`،
خط بالاش رو پیدا کن:

```php
define('SECRET_KEY', 'NETpKWZLfiVkVimmjvMd'); // <-- CHANGE THIS
```

و یه رشته‌ی دلخواه دیگه بذار جاش (هرچی عجیب‌تر بهتر). این صفحه هر بار که
بازش کنی، همه‌ی جواب‌هایی که تا الان ثبت شده رو نشون می‌ده (جدیدترین اول)،
همراه با تاریخ/ساعت/مکان/آدرس انتخابی و اینکه هر «نه» دقیقاً چند بار زده
شده.

## آپلود روی هاست

این پروژه دیگه فقط استاتیک نیست - برای ذخیره‌ی جواب‌ها به PHP نیاز داره؛
پس هاستی که انتخاب می‌کنی باید از PHP پشتیبانی کنه (تقریباً همه‌ی هاست‌های
فیریِ رایج - مثل InfinityFree, 000webhost, AwardSpace, Byethost و
مشابه‌شون - این‌جوری‌ان؛ اگه هاستت از این خانواده نیست بگو تا روش
مخصوص همونو بگم).

1. تو پنل هاست (معمولاً cPanel یا مشابهش)، برو تو File Manager یا با FTP
   وصل شو.
2. کل محتوای همین پوشه (`index.html`, `save.php`, `view.php`, `data/`,
   `assets/`) رو بریز تو `public_html` (یا هر پوشه‌ای که ریشه‌ی سایتت رو
   نشون می‌ده).
3. مطمئن شو پوشه‌ی `data` قابل نوشتنه. اکثر هاست‌ها خودکار درست کار می‌کنن؛
   اگه بعد از تست، جواب‌ها تو `view.php` نیومدن، از File Manager روی پوشه‌ی
   `data` راست‌کلیک کن → Permissions → بذار رو `755`. اگه بازم نشد، امتحان
   کن `777` (خیلی از هاست‌های رایگان همینو می‌خوان).
4. رمز `view.php` رو عوض کن (بالا توضیح دادم) - این قدمو فراموش نکن.
5. آدرس سایتت رو باز کن، خودت یه بار کامل تا آخر بری تست کن، بعد
   `view.php?key=...` رو باز کن و ببین جوابت اومده یا نه.

اگه هاستت PHP نداره (مثلاً یه هاستِ کاملاً استاتیک مثل GitHub Pages یا
Netlify)، این روش ذخیره‌سازی کار نمی‌کنه و باید یه جایگزین دیگه (مثل یه
سرویس فرم بیرونی) براش بذاریم - بگو تا اونو هم آماده کنم.

## تغییرات نسبت به نسخه‌ی قبل

**آخرین دور:**

- **نه‌ی مرحله‌ی ۲ دیگه فرار نمی‌کنه** - سرجاش می‌مونه و فقط با هر بار زدن
  کوچیک‌تر می‌شه؛ الان بعد از **۳ بار** (قبلاً ۵ بار و فرار می‌کرد) وارد
  لحظه‌ی اوج می‌شه.
- **نه‌ی مرحله‌ی ۳ هم دیگه فرار نمی‌کنه** - سرجاش می‌مونه و فقط فونت/شکلش
  عوض می‌شه؛ الان بعد از **۴ بار** (قبلاً ۵ بار) وارد لحظه‌ی اوج می‌شه.
  (مرحله‌ی ۱ همون فرارکردنِ قبلی رو داره، ۵ بار.)
- **دیگه هیچ فایلی رو سیستم پارتنرت دانلود نمی‌شه.** جواب‌ها (تاریخ/ساعت/
  مکان/آدرس + دقیقاً چند بار هر «نه» زده شده) ساکت با `save.php` می‌رن رو
  خودِ هاست ذخیره می‌شن؛ فقط خودت، با رمزی که تو `view.php` می‌ذاری،
  می‌تونی ببینیشون. جزئیات کامل تو بخش «جواب‌ها رو کجا می‌بینم؟» بالا.

**دور قبل:**

- **باگ اصلی فیکس شد:** دکمه‌ی «نه» برای فرار از موس/لمس با `appendChild`
  می‌رفت زیر `<body>` (تا از `overflow:hidden` کارت فرار کنه) ولی هیچ‌وقت
  برنمی‌گشت سرجاش - برای همین اگه قبل از رسیدن به لحظه‌ی اوج (یعنی با کمتر
  از ۵ بار فرار) می‌زدی «آره»/«بعدی»، دکمه‌ی «نه»‌ی همون مرحله (با همون
  موقعیت/چرخش آخرش) رو مرحله‌ی بعد هم می‌موند. حالا هر بار عوض شدن مرحله
  (`StageManager.goTo`)، هر سه دکمه‌ی «نه» کامل ریست می‌شن: برمی‌گردن سرجای
  اصلی‌شون تو DOM، همه‌ی استایل‌های اینلاین (موقعیت/چرخش/فونت/شکل) پاک
  می‌شه، و حال‌وهوای صفحه (تاریکی/وینیت/بلور) هم صفر می‌شه - چه از مسیر
  اوج رد شده باشی چه مستقیم زده باشی «بعدی».
- **پلی‌لیست ویدیو/موزیکِ پس‌زمینه دیگه گیر نمی‌کنه:** اگه یه فایل بعدی تو
  پلی‌لیست (مثلاً `background2.mp4` یا `song2.mp3`) وجود نداشته باشه، قبلاً
  ویدیو رو فریم آخر می‌موند (یا موزیک برای همیشه ساکت می‌شد). حالا خودش رد
  می‌شه به فایل بعدی و اگه هیچ‌کدوم نبود، دوباره برمی‌گرده به همون فایلی که
  داری (مثلاً فقط `background1.mp4`) - یعنی همیشه یه چیزی در حال پخشه.
- **تقویم مرحله‌ی ۲ حالا شمسیه** (فروردین تا اسفند، سال ۱۴۰۵ و...) به‌جای
  میلادی؛ تبدیل تاریخ کاملاً تو همین فایله (بدون کتابخونه‌ی بیرونی) و روی
  بیش از ۳۰۰۰ تاریخ تست شده.
- بعد از فرار پنجم/ششمِ «نه»: خودِ دکمه کوچیک می‌شه و محو (`zap`)، همون لحظه
  ویدیوی اوج پخش می‌شه، و دکمه‌ی اصلی مرحله (آره/بعدی/تمومه) **بزرگ‌تر و
  با گلوی بیشتر** می‌شه تا واضح باشه الان نوبت کلیک کردن رو اونه.
- «نه»‌یِ مرحله‌ی سوم (آخرین مرحله‌ای که «نه» داره) هر بار که فرار می‌کنه
  **فونت و شکلش هم عوض می‌شه** (وزن/سبک فونت و بردر-رادیوس تصادفی) - یه
  ذره دیوونه‌تر می‌شه هر چی بیشتر فرار می‌کنه.
- **فیلدهای مرحله‌ی ۲ و ۳ اجباری‌ان:** مرحله‌ی ۲ تا تاریخ+ساعت انتخاب نشه
  دکمه‌ی «بعدی» غیرفعاله (همون قبلی بود). مرحله‌ی ۳ حالا علاوه بر آدرس،
  انتخاب مکان هم صریحاً چک می‌شه - اگه مکان انتخاب نشده باشه، کارت‌های
  مکان تکون می‌خورن (shake) تا بفهمی چی کمه.
- ~~هر بار که تا آخر بری، یه فایل Word (`.doc`) خودکار دانلود می‌شه...~~
  *(این روش تو دور بعدی حذف شد و جاش ذخیره‌ی ساکت روی هاست اومد - بخش
  «آخرین دور» بالا رو ببین.)*
- **موزیک حالا به‌صورت پیش‌فرض/خودکار پخش می‌شه** - دیگه نیازی به لمس کردن
  چیزی نیست. اگه مرورگر پخش خودکارِ صدادار رو بلاک کنه (این محدودیت
  خودِ مرورگره، هیچ سایتی نمی‌تونه دورش بزنه)، سایت بی‌سروصدا و بدون هیچ
  پیامی، اولین لمس/کلیک/دکمه رو به‌عنوان فرصت پخش در نظر می‌گیره.
- **مکانیزم «نه» + تاریک‌شدن تو هر سه مرحله‌ی اول هست**، نه فقط صفحه‌ی
  اول - هر مرحله ویدیوی اوجِ خودشو داره (`nikki.mp4`, `nikki2.mp4`,
  `nikki3.mp4`).
- **لحظه‌ی اوج کاملاً اختصاصیِ ویدیوته** - پس‌زمینه و موزیک هر دو ساکت
  می‌شن؛ صفحه‌ی ایموجیِ قبلی خیلی کوچیک و بی‌رنگ شده (فقط یه قلب محو، فقط
  برای وقتی که هنوز فایل ویدیو رو نذاشتی) و دیگه نقشی نداره وقتی ویدیوی
  واقعی هست.
- ویدیوها همچنان **قابل ردشدن**‌ان (لمس برای ادامه بعد از ۱.۵ ثانیه)، برای
  وقتی که فایل دیر لود بشه یا پارتنرت وسط کاری باشه.

## اگه خواستی چیزی رو عوض کنی

تو `index.html`:

- هر سه `createRejectFlow({...})` نزدیک انتهای کد - متن‌های هر مرحله
  (`messages`، تعداد آرایه = تعداد دفعاتی که «نه» باید زده بشه تا اوج)،
  اسم ویدیوی اوجش (`climaxVideo`)، جمله‌ی بعد از اوج (`afterClimaxHTML`)،
  دکمه‌ی جفتش که بزرگ می‌شه (`yesBtnId`)، و رفتار دکمه‌ی «نه»‌اش:
  `roams:true` یعنی فرار می‌کنه (مرحله‌ی ۱)، `roams:false` یعنی سرجاش
  می‌مونه؛ اگه `roams:false` بود، `shrinkOnDodge:true` باعث کوچیک‌شدن
  می‌شه (مرحله‌ی ۲) و `warpOnDodge:true` باعث تغییر فونت/شکل می‌شه
  (مرحله‌ی ۳) - می‌تونی هر دوتاشونم با هم `true` کنی اگه خواستی.
- `ThemeManager.overlayColors` - رنگ تاریک‌شدن صفحه در هر سطح
- `VideoManager.playlist` / `MusicManager.playlist` - اگه اسم فایل‌ها رو
  عوض کردی
- `CalendarManager.monthNames` - اسم ماه‌های شمسی (اگه خواستی چیزی رو
  عوض کنی؛ تبدیل تاریخ خودش تو شیء `Jalaali` بالای همون بخشه)
- `SubmissionManager` - چه فیلدهایی به `save.php` فرستاده می‌شه
- متن پیام پایانی - داخل `#stage4 .final-message` تو HTML

تو `save.php` / `view.php`:

- `view.php` → `SECRET_KEY` - رمز صفحه‌ی خصوصی‌ت (حتماً عوضش کن)
- `save.php` → اگه خواستی فیلد جدیدی هم ذخیره بشه، هم اینجا و هم تو
  `SubmissionManager.send()` تو `index.html` باید اضافه‌ش کنی
