# یه سوال کوچولو 💌 — راهنمای پروژه

## ساختار پوشه‌ها

```
index.html              <- کل سایت (HTML+CSS+JS تو همین یه فایل)
assets/
  videos/
    background1.mp4     <- پلی‌لیست ویدیوی پس‌زمینه (اختیاری)
    background2.mp4
    background3.mp4
    nikki.mp4            <- ویدیوی اوجِ مرحله‌ی ۱ (سوال اصلی) (اختیاری)
    nikki2.mp4           <- ویدیوی اوجِ مرحله‌ی ۲ (تاریخ/ساعت) (اختیاری)
    nikki3.mp4           <- ویدیوی اوجِ مرحله‌ی ۳ (انتخاب مکان) (اختیاری)
  music/
    song1.mp3            <- پلی‌لیست موزیک پس‌زمینه، پخش خودکار (اختیاری)
    song2.mp3
    song3.mp3
  sounds/
    glitch.mp3           <- افکت صدای لحظه‌ی چهارم هر مرحله (اختیاری)
```

هیچ‌کدوم از فایل‌های بالا اجباری نیستن. همین الان که هیچی داخلشون نیست،
سایت کامل و قشنگ کار می‌کنه. هر وقت فایل‌ها رو با همین اسم‌های دقیق اضافه
کنی، خودکار جایگزین می‌شن - نیازی به تغییر کد نیست.

## چطور ببینمش؟

کافیه `index.html` رو باز کنی. برای اینکه پارتنرت هم ببینتش، کل پوشه
(`index.html` + `assets`) رو کنار هم نگه دار و بفرست.

## داستان مراحل

هر سه مرحله‌ی اول (سوال اصلی، تاریخ/ساعت، انتخاب مکان) دقیقاً همون مکانیزم
رو دارن: یه دکمه‌ی «نه» که با نزدیک شدن موس یا لمس گوشی فرار می‌کنه. هر بار
فرار، فضای صفحه یه پله تاریک‌تر/سردتر/لرزون‌تر می‌شه (۴ سطح: تاریکی و افت
نور و موزیک، رنگ سردتر و لرزش، وینیت و بلور، چشمک+افکت صدا). دکمه‌ی اصلیِ
هر مرحله (آره / بعدی / تمومه) همیشه و مستقل از این جریان کار می‌کنه.

بار پنجم که «نه» فرار می‌کنه، وارد یه لحظه‌ی سینمایی می‌شیم: چشمک، افکت
گلیچ، صفحه سیاه، و ویدیوی مخصوص همون مرحله (nikki / nikki2 / nikki3)
تمام‌صفحه پخش می‌شه. **درست همون لحظه، ویدیوی پس‌زمینه و موزیک کاملاً
ساکت می‌شن - فقط و فقط همون ویدیو دیده و شنیده می‌شه.** بعد از تموم شدنش
(یا لمس برای رد شدن)، یه جمله‌ی کوتاه میاد و بعدش می‌ره مرحله‌ی بعد؛
پس‌زمینه و موزیک هم به‌آرومی برمی‌گردن.

1. **صفحه‌ی اول** - «حاضری باهام بیای بیرون؟» → اوج: `nikki.mp4`
2. **تاریخ و ساعت** - تقویم شیشه‌ای دست‌ساز + انتخاب ساعت → اوج: `nikki2.mp4`
3. **انتخاب مکان** - ۶ کارت (کافه، شهربازی، رستوران، دوردور، پیاده‌روی شبانه،
   سینما) + آدرس → اوج: `nikki3.mp4`
4. **پیام آخر** - بدون دکمه‌ی «نه» و بدون این مکانیزم؛ فقط پیام پایانی،
   قلب‌های خروجی، کانفتی، و فید موزیک.

در تمام مراحل: شیشه‌ای‌بودن (Glassmorphism)، نور دنبال‌کننده‌ی موس،
پارالاکس، ذرات شناور، ریپل روی دکمه‌ها، و موزیکِ خودکار هست.

## تغییرات نسبت به نسخه‌ی قبل

- **باگ اصلی فیکس شد:** دکمه‌ی «نه» برای فرار از موس/لمس با `appendChild`
  می‌رفت زیر `<body>` (تا از `overflow:hidden` کارت فرار کنه) ولی هیچ‌وقت
  برنمی‌گشت سرجاش - برای همین اگه قبل از رسیدن به لحظه‌ی اوج (یعنی با کمتر
  از ۵ بار فرار) می‌زدی «آره»/«بعدی»، دکمه‌ی «نه»‌ی همون مرحله (با همون
  موقعیت/چرخش آخرش) رو مرحله‌ی بعد هم می‌موند. حالا هر بار عوض شدن مرحله
  (`StageManager.goTo`)، هر سه دکمه‌ی «نه» کامل ریست می‌شن: برمی‌گردن سرجای
  اصلی‌شون تو DOM، همه‌ی استایل‌های اینلاین (موقعیت/چرخش/فونت/شکل) پاک
  می‌شه، و حال‌وهوای صفحه (تاریکی/وینیت/بلور) هم صفر می‌شه - چه از مسیر
  اوج رد شده باشی چه مستقیم زده باشی «بعدی».
- **پلی‌لیست ویدیو/موزیکِ پس‌زمینه دیگه گیر نمی‌کنه:** اگه یه فایل بعدی تو
  پلی‌لیست (مثلاً `background2.mp4` یا `song2.mp3`) وجود نداشته باشه، قبلاً
  ویدیو رو فریم آخر می‌موند (یا موزیک برای همیشه ساکت می‌شد). حالا خودش رد
  می‌شه به فایل بعدی و اگه هیچ‌کدوم نبود، دوباره برمی‌گرده به همون فایلی که
  داری (مثلاً فقط `background1.mp4`) - یعنی همیشه یه چیزی در حال پخشه.
- **تقویم مرحله‌ی ۲ حالا شمسیه** (فروردین تا اسفند، سال ۱۴۰۵ و...) به‌جای
  میلادی؛ تبدیل تاریخ کاملاً تو همین فایله (بدون کتابخونه‌ی بیرونی) و روی
  بیش از ۳۰۰۰ تاریخ تست شده.
- بعد از فرار پنجم/ششمِ «نه»: خودِ دکمه کوچیک می‌شه و محو (`zap`)، همون لحظه
  ویدیوی اوج پخش می‌شه، و دکمه‌ی اصلی مرحله (آره/بعدی/تمومه) **بزرگ‌تر و
  با گلوی بیشتر** می‌شه تا واضح باشه الان نوبت کلیک کردن رو اونه.
- «نه»‌یِ مرحله‌ی سوم (آخرین مرحله‌ای که «نه» داره) هر بار که فرار می‌کنه
  **فونت و شکلش هم عوض می‌شه** (وزن/سبک فونت و بردر-رادیوس تصادفی) - یه
  ذره دیوونه‌تر می‌شه هر چی بیشتر فرار می‌کنه.
- **فیلدهای مرحله‌ی ۲ و ۳ اجباری‌ان:** مرحله‌ی ۲ تا تاریخ+ساعت انتخاب نشه
  دکمه‌ی «بعدی» غیرفعاله (همون قبلی بود). مرحله‌ی ۳ حالا علاوه بر آدرس،
  انتخاب مکان هم صریحاً چک می‌شه - اگه مکان انتخاب نشده باشه، کارت‌های
  مکان تکون می‌خورن (shake) تا بفهمی چی کمه.
- **هر بار که تا آخر بری، یه فایل Word (`.doc`) خودکار دانلود می‌شه** با
  تاریخ/ساعت/مکان/آدرسی که انتخاب شده و دقیقاً چند بار هر «نه» فرار کرده
  (به تفکیک هر مرحله + مجموع). یه دکمه‌ی «دانلود خلاصه‌ی قرارمون» هم ته
  صفحه‌ی آخر هست اگه خواستی دوباره دانلودش کنی. بدون کتابخونه‌ی بیرونی -
  خودِ Word/LibreOffice/Google Docs فایل رو باز می‌کنن.
- **موزیک حالا به‌صورت پیش‌فرض/خودکار پخش می‌شه** - دیگه نیازی به لمس کردن
  چیزی نیست. اگه مرورگر پخش خودکارِ صدادار رو بلاک کنه (این محدودیت
  خودِ مرورگره، هیچ سایتی نمی‌تونه دورش بزنه)، سایت بی‌سروصدا و بدون هیچ
  پیامی، اولین لمس/کلیک/دکمه رو به‌عنوان فرصت پخش در نظر می‌گیره.
- **مکانیزم «نه» + تاریک‌شدن تو هر سه مرحله‌ی اول هست**، نه فقط صفحه‌ی
  اول - هر مرحله ویدیوی اوجِ خودشو داره (`nikki.mp4`, `nikki2.mp4`,
  `nikki3.mp4`).
- **لحظه‌ی اوج کاملاً اختصاصیِ ویدیوته** - پس‌زمینه و موزیک هر دو ساکت
  می‌شن؛ صفحه‌ی ایموجیِ قبلی خیلی کوچیک و بی‌رنگ شده (فقط یه قلب محو، فقط
  برای وقتی که هنوز فایل ویدیو رو نذاشتی) و دیگه نقشی نداره وقتی ویدیوی
  واقعی هست.
- ویدیوها همچنان **قابل ردشدن**‌ان (لمس برای ادامه بعد از ۱.۵ ثانیه)، برای
  وقتی که فایل دیر لود بشه یا پارتنرت وسط کاری باشه.

## اگه خواستی چیزی رو عوض کنی (تو `index.html`)

- هر سه `createRejectFlow({...})` نزدیک انتهای کد - متن‌های هر مرحله
  (`messages`)، اسم ویدیوی اوجش (`climaxVideo`)، جمله‌ی بعد از اوج
  (`afterClimaxHTML`)، دکمه‌ی جفتش که بزرگ می‌شه (`yesBtnId`)، و اینکه
  فونت/شکلش موقع فرار عوض بشه یا نه (`warpOnDodge: true/false`)
- `ThemeManager.overlayColors` - رنگ تاریک‌شدن صفحه در هر سطح
- `VideoManager.playlist` / `MusicManager.playlist` - اگه اسم فایل‌ها رو
  عوض کردی
- `CalendarManager.monthNames` - اسم ماه‌های شمسی (اگه خواستی چیزی رو
  عوض کنی؛ تبدیل تاریخ خودش تو شیء `Jalaali` بالای همون بخشه)
- `SummaryManager` - متن و ظاهر فایل Word خروجی آخر کار
- متن پیام پایانی - داخل `#stage4 .final-message` تو HTML
